It's like a website builder for scouting apps.
There's still a lot more work to be done on it, but you can try it out now.
This started out as my PLTW Capstone project to make it easier for teams to create scouting apps.
It was initially just a school project, but a team ended up actually wanting to use this for the 2026 season due to changes in their scouting data needs mid-season.
This app is great for easily building and modifying a scouting app that can be run as a PWA.
I'll add more tutorials and things when it gets closer to being fully finished.

ThunderScout is not associated with any specific FIRST Robotics team.
